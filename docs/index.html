Qué contiene este MVP web

Fase A
Manual operativo Capturas UI Roadmap web Base para dominio
  1. Manual de uso completo: referencia funcional de la app Android (modos, métricas, filtros, simulación, copytrade).
  2. Presentación pública: página simple para compartir el proyecto y validar publicación en dominio propio.
  3. Estructura extensible: permite evolucionar a web funcional sin romper el dominio ni la ruta base.
  4. Zero backend: despliegue rápido, barato y con menos puntos de fallo.
La web funcional vendrá después. Este paso evita mezclar despliegue de infraestructura con la complejidad del motor meteo/trading.

Pasos de publicación

Render + DonDominio
  1. Subir este repo a GitHub con docs/index.html y render.yaml.
  2. Crear Static Site en Render desde el repo.
  3. Sincronizar Blueprint (Render leerá render.yaml).
  4. Añadir custom domain polymeteo.caplatemp.xyz.
  5. Crear CNAME en DonDominio host polymeteo -> *.onrender.com.
  6. Esperar propagación y validar SSL automático.

Requisitos para la web funcional

Core futuro
  • Backend centralizado para scraping, proveedores y lógica de decisión.
  • API propia para servir ciudades, detalle, mercados y señales ya calculadas.
  • Realtime (SSE/WebSocket) para copytrade y cambios de mercado.
  • Gestión segura de secretos (nunca en frontend).
  • Persistencia (paper trading, preferencias, cache, histórico calibrado).
