# polyMeteo Web (Fase B1 scaffold)

Frontend web mínimo para visualizar `CIUDADES` y `DETALLE` en navegador.

## Dependencia actual

Usa el backend mock en `backend/web_api`.

## Ejecutar local

1. Arranca API + static server:

```bash
cd backend/web_api
npm run dev
```

2. Abre:

- `http://localhost:8788/app`
